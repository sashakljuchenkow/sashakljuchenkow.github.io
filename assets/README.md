# Photo assets

Place the original portfolio images in these folders:

- `portrait/` — Portrait
- `fashion/` — Fashion
- `art/` — Contemporary Art
- `documentary/` — Documentary
- `landscape/` — Landscape

Recommended format: WebP or JPG. Keep filenames simple, for example `01.webp`, `02.webp`, `03.webp`.

The website currently uses the first image from each category as its featured image.
