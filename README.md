# Sasha Kljuchenkow — Portfolio

Static portfolio site designed for GitHub Pages.

## Replace the placeholders

In `index.html`, replace the `div.image-placeholder` blocks with real `<img>` elements, for example:

```html
<div class="image-placeholder">
  <img src="assets/portrait-01.jpg" alt="Portrait">
</div>
```

Then add the corresponding files to `assets/`.

## Publish on GitHub Pages

Create a public repository named:

`YOUR-GITHUB-USERNAME.github.io`

Upload `index.html`, `style.css`, `script.js`, and the `assets` folder.

In the repository go to **Settings → Pages** and choose the publishing source. GitHub Pages will publish the site at:

`https://YOUR-GITHUB-USERNAME.github.io/`
